**BloodLink** is a comprehensive Android application designed to bridge the gap between blood donors, recipients, and blood banks. By leveraging real-time data and location services, BloodLink aims to make the process of finding and donating blood seamless and efficient.

---

## ✨ Features

### For Donors
*   **Easy Registration**: Simple sign-up process with health details.
*   **Find Requests**: View urgent blood requirements nearby.
*   **Donation History**: Keep track of previous donations.
*   **Profile Management**: Update contact and health information.

### For Agencies (Blood Banks)
*   **Inventory Management**: Track blood stock levels in real-time.
*   **Donor Database**: Access a list of registered donors for emergencies.
*   **Request Handling**: Create and manage blood requests.

### For Admins
*   **Verification**: Verify agencies and donors to ensure safety.
*   **System Oversight**: Monitor app usage and handle reports.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

*   **Android Studio**: Iguana or later recommended.
*   **JDK**: Version 17 or higher.
*   **Firebase Account**: Required for backend services.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Subhadip-sonai/Project_BloodLink.git
    cd Project_BloodLink
    ```

2.  **Open in Android Studio**
    *   Launch Android Studio.
    *   Select `File > Open` and choose the project directory.

3.  **Firebase Setup (Crucial Step)**
    *   Create a project in the [Firebase Console](https://console.firebase.google.com/).
    *   Add an Android app with package name: `com.sonai.bloodlink`.
    *   Download `google-services.json`.
    *   Move the file to: `app/google-services.json`.
    *   Enable **Authentication** (Email/Password).
    *   Enable **Realtime Database** and **Storage**.

4.  **Build the Project**
    *   Go to `Build > Make Project` or press `Ctrl+F9`.
    *   Sync Gradle if prompted.

5.  **Run the App**
    *   Connect your device or start an emulator.
    *   Click `Run`.
